Frequently asked questions

Will the fancy text work everywhere?

Mostly yes — it is real Unicode text, not images. Some older devices lack fonts for a few decorative blocks, so always check a preview.

What is kashida elongation?

Kashida (تطويل/كشيدة) is the horizontal stroke Arabic calligraphy uses to stretch words. The tool inserts tatweel between joinable letters automatically.

Is it free?

Yes — unlimited for personal use. Pro unlocks custom style presets.
